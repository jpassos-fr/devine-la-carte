DEVINE LA CARTE !

Installation / mise a jour GitHub Pages :
1. Envoyer les fichiers de ce dossier a la racine du depot GitHub.
2. Pour mettre a jour un site existant, remplacer index.html et sw.js.
3. Dans Chrome sur Android, ouvrir le site et actualiser la page. Si l'ancienne version reste affichee, fermer l'application et rouvrir le site apres quelques instants.

Fonctionnement :
- Ajouter les joueurs qui devineront.
- La personne qui utilise le telephone mime la carte.
- Choisir Enfant (4-6 ans) ou Adulte avant chaque carte.
- Les autres joueurs disent leur prenom puis le mot.
- La reconnaissance vocale propose un point ; il faut confirmer avant attribution.
- Le bouton de confirmation manuelle permet de choisir un gagnant uniquement si necessaire.
- Le telechargement de cartes necessite une connexion Internet.

La reconnaissance vocale depend du navigateur et peut necessiter Internet. Elle n'identifie pas les voix de facon fiable : les joueurs doivent annoncer leur prenom.
